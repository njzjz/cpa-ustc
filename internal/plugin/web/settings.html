CLIProxyAPI / USTC

中科大词元计划

网页完成配置；模型账号直接加入 CPA 号池，不另建调度器。

管理连接

插件页面不读取管理中心的私有存储。首次使用请填写本台 CPA 的管理密钥（不是客户端 Key 或科大 API Key），仅保留在当前页面内存。

网络与插件设置

保存到 CPA 自己的插件配置并由 CPA 热更新；通用插件配置弹窗也能编辑这些字段。

iWAN 校外代理

全部模型账号共用一条 iWAN 通路。首次授权需在浏览器登录后，将页面按钮中的 com.panabit.mobile://… 回调链接粘贴到此处；无需返回终端。

打开科大 iWAN 授权页面

安装按钮会下载固定版本的第三方 ustc-iwan，并校验发布附件 SHA-256；它不是学校官方客户端，不修改系统 VPN。

CPA 号池 · ustc

支持多个科大账号或多个 API Key。选择、轮询、故障切换、禁用和删除均复用 CPA；重复添加同一账号更新原凭据。

打开科大统一身份认证

添加其他科大账号时，请先在学校认证页面退出当前账号或使用独立浏览器会话。密码和 MFA 只在学校官方页面输入。

远程 / Docker 部署：提交浏览器回调

若浏览器跳到无法连接的 127.0.0.1 页面，将地址栏的完整 URL 粘贴到下方；授权码不保存在浏览器存储中。

添加 API Key

二选一。直接输入的 Key 保存到 CPA 私有凭据文件；环境变量引用不保存 Key，CPA 进程必须已继承该变量。

统一认证账号支持在 CPA 原生额度页或此处查询各档剩余额度和重置时间。API Key 模式需到学校控制台查看；平台额度不是 token 数，各窗口和共享账户不能相加。
